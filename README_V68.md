# SWGOH Optimizer — V68 Dashboard Reconstruction

V68 reconstructs the Dashboard around the approved Galactic Command visual direction.

## Dashboard structure
- Cinematic command header using the supplied fleet image.
- Left navigation integrated into the supplied vertical city image.
- Hero using the supplied fleet image with a distinct crop and blue/cyan grade.
- Profile name and Ally Code integrated into the hero profile console.
- Four connected HUD telemetry metrics: Mods, Personnages, Vaisseaux, Unités totales.
- Galactic Power rebuilt as a central holographic instrument with Total / Terrestre / Spatial.
- V176 mod-speed distribution retained as live telemetry cards.
- Lightweight animated HUD scan, glow and ring motion.

## Functional scope
This version changes the Dashboard presentation only. Existing roster, mods analysis, optimizer, worker and V176 data logic are retained.
