Selimna’s Holocron V78 — Référentiel Kyber

Le classement TOP 10 tient désormais compte, lorsqu’un profil est disponible, des préférences Kyber du personnage pour les sets, les primaires par emplacement et les statistiques secondaires. Le score reste un indicateur de compatibilité de mods, pas une mesure de dégâts, de victoire ou de performance simulée.

Référentiel retenu : Kyber pour les objectifs statistiques des équipes alliées et pour les profils de référence des adversaires. Les profils SWGOH.GG intégrés décrivent des tendances de mods (notamment le Top 1000 GAC) ; ils ne constituent pas des statistiques exactes de chaque adversaire.

La simulation de combat complète reste une étape distincte : elle nécessitera un modèle validé de jauge de tour, capacités, dégâts, buffs, debuffs et effets aléatoires.
