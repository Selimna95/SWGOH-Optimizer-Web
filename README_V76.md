# Selimna's Holocron V76

V76 sépare l'espace « Top 10 échanges » du Dashboard. Le nouvel espace décrit la méthode souhaitée : examiner les mods des personnages bien équipés, repérer les mods les moins adaptés, rechercher des bénéficiaires parmi les personnages au moddage très faible, faible ou incomplet, puis évaluer le gain net de l'échange.

Important : le classement automatique des dix échanges n'est pas encore implémenté. Aucun résultat ou gain fictif n'est affiché. Les fonctionnalités préexistantes sont conservées.
