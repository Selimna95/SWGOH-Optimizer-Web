# Selimna’s Holocron V88

V88 ajoute le code couleur du niveau et de la qualité du mod dans les cartes d’échange du TOP 10. Le chiffre utilise la couleur des dots (blanc pour 1–5, doré pour 6) et la lettre reprend la couleur de qualité (A doré, E blanc, etc.). Les informations de set, emplacement, primaire et vitesse restent affichées.
