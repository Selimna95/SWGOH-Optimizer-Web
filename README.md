# SWGOH Optimizer Web — V37

V37 est une évolution visuelle de V36. La navigation passe en barre horizontale afin de donner davantage de largeur aux tableaux et rapports. La Puissance Galactique est plus compacte et l'identité Star Wars / cockpit est renforcée par une palette multi-couleurs et des effets HUD.

Aucune logique métier n’est volontairement modifiée.
