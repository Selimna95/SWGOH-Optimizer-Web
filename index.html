RELAIS CLOUDFLARE

Le navigateur bloque actuellement la lecture directe de SWGOH.GG à cause du CORS. V8 utilise donc un petit Cloudflare Worker gratuit. Il ne demande aucun logiciel à installer sur votre PC.

RELAIS PRÉCONFIGURÉ
MISE EN ROUTE
  1. Le Worker Cloudflare est déjà configuré pour ce projet. Le fichier cloudflare-worker/worker.js est fourni pour réinstaller le relais si nécessaire.
  2. Déployer le Worker et copier son adresse workers.dev.
  3. Coller cette adresse dans le champ ci-dessus puis cliquer sur ENREGISTRER LE RELAIS.
  4. Revenir au DASHBOARD, saisir l'Ally Code et cliquer sur CHARGER MON PROFIL.
  5. Si SWGOH.GG refuse aussi la requête du Worker, le journal l'indiquera et l'import JSON restera disponible.

Important : le Worker ne reçoit pas votre mot de passe EA/jeu. Il ne fait qu'une requête publique vers SWGOH.GG.
