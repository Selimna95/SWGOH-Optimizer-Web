# Mod icon integration

The application now renders the official SWGoH mod texture names by set + slot + tier, with the official dot indicator (1-6) and mod level overlay.

Sources referenced by the implementation:
- SWGoH Wiki mod assets: https://swgoh.wiki/wiki/Mod_Battles
- SWGoH Wiki Mods: https://swgoh.wiki/wiki/Mods

The browser resolves the game texture through the Wiki file redirect endpoint, so no third-party icon pack is bundled into the repository.
