# SWGOH Optimizer Web — V31.2

## New feature: Réaffectation intelligente des mods

- Select an equipped mod from a character report or mod inventory.
- Choose the secondary stat to search for.
- Search equipped mods belonging to characters classified by the existing V176 statuses:
  - INCOMPLETS
  - TRÈS FAIBLES
  - FAIBLES
- Characters classified MOYENS are protected by default.
- Unlocking MOYENS requires an explicit confirmation and then enables the checkbox.
- No scoring, ranking, automatic transfer, or automatic replacement is performed.
- Results show the owner, status, slot, set, primary, requested secondary value, other secondaries and mod level.
- Clicking a result opens the existing mod detail.

## Existing V30 functionality retained

- Cloudflare relay preset.
- Roster / 406 units / mods loading.
- Dashboard galactic power split.
- Data tab without Set / Slot / State / Minimum Level module filters.
- Optimizer default: 5 builds.
- V176 mod analysis, relic conversion and Speed 6/6 logic.
- `assets/backgrounds/` structure.
