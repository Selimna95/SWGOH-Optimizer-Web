# SWGOH Optimizer Web — V31.3

## Réaffectation de mods
- Sélection d'un mod précis depuis le rapport/inventaire.
- Recherche sans scoring : l'utilisateur choisit la secondaire à rechercher.
- Catégories autorisées : Incomplets, Très faibles, Faibles.
- Moyens protégés par défaut et accessibles uniquement après validation spéciale.
- Le propriétaire du mod sélectionné est exclu des candidats.
- **Même slot obligatoire** : Square→Square, Arrow→Arrow, Diamond→Diamond, Triangle→Triangle, Circle→Circle, Cross→Cross.
- **Même set obligatoire** : le mod candidat doit appartenir au même set que le mod sélectionné.
- Aucun transfert automatique : les résultats sont uniquement des propositions de remplacement.

## Données / UI
- Dashboard, Données, Analyse Mods et Optimizer conservés.
- Assets de fond dans `assets/backgrounds/`.
